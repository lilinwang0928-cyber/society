# 康版國中公民（一）　進入群體的個人生活　互動學習單

12 份互動教材，單檔 HTML、無外部相依。

## 使用方式

把整個資料夾的檔案放在同一層，用瀏覽器開啟 `index.html` 即可。
建議使用 Chrome 或 Safari（語音朗讀功能需要）。

## 三種教材型態

**逐課學習單**（L1–L6）
概念導覽（可展開的概念圖）→ 重點學習（挖空填答、對照表）→ 小試身手（20 題隨機出題、即時解析）。
L3 另有「親屬判斷」、L5 另有「議事練習」兩個專項練習分頁。

**段考評量**（E12、E34、E56）
一次作答完再交卷，交卷後逐題顯示對錯與解析，並依會考標準換算精熟／基礎／待加強等級，附各小節弱項統計。可切換「只看錯題」。

**素養專區**（S12、S34、S56）
閱讀文本 → 選擇題 → 開放式寫作（自動存檔）。

## 兩種使用方式

**分檔版**：把所有檔案放在同一層，開啟 `index.html`，從總覽頁點進各份學習單。適合上傳到 GitHub Pages 或 Netlify。

**整冊版**：`國中公民一-進入群體的個人生活-整冊單檔.html` 單獨一個檔案就能用，12 份全部內嵌其中，用頂端的課次列切換，也可用鍵盤左右鍵翻頁，會記住上次看到哪一份。適合傳給學生或用隨身碟帶著跑。

> 整冊版若以 `file://` 直接開啟，部分瀏覽器會限制內嵌頁面存取 localStorage，成績可能無法保存（功能本身仍正常）。放到網站上或用本機伺服器開啟即可正常記錄。

## 陪讀吉祥物　熊審判

法袍、法槌、天平的臺灣黑熊，陪學生走完整個單元。

- **進站自我介紹**：每一份開啟時，熊審判會說明這一份的重點與該注意的地方，並語音朗讀。可勾選「下次不要自動朗讀」，設定會記住。
- **不定時鼓勵小語**：每隔 70～130 秒隨機出現一則（12 則輪播，不重複），文案取自角色圖。
- **完成時打氣**：測驗結算、段考交卷、素養開放題寫滿 30 字，熊熊都會出來。
- 關掉後右下角會留一顆小頭像，點一下可以再叫他出來。
- **鼓勵小語抽籤筒**：介紹卡與小語卡都有連結，可開啟熊審判的 108 句中英雙語抽籤筒
  （<https://bear-judge-encouragement.lilinwang0928.chatgpt.site>），總覽頁的「延伸教材」也有入口。

## 語音朗讀

每一份都支援語音導覽：單段朗讀（🔊）與整段連續朗讀，語速 0.6～1.4 可調。
測驗區可選擇「連選項一起念」，作答後再按會加念正解與解析。

朗讀文字經過口語化處理，例如「110／113」念成「一一零／一一三」、「12～18歲」念成「12到18歲」、挖空處念成「空格」。

## 紀錄儲存

成績與作答內容存在瀏覽器的 localStorage，換裝置或清除瀏覽資料會重新計算。
總覽頁會讀取各份的最佳成績並顯示完成進度。
